# MC458 — Projeto e Análise de Algoritmos I

Repositório com as atividades desenvolvidas para a disciplina **MC458 — Projeto e Análise de Algoritmos I**, da Universidade Estadual de Campinas (Unicamp).

As cinco tarefas foram implementadas em Python e exploram estruturas de dados, árvores, ordenação, programação dinâmica e algoritmos gulosos.

## Conteúdo

| Tarefa | Tema | Descrição |
| --- | --- | --- |
| Tarefa 1| Conjunto dinâmico | Mantém um subconjunto de inteiros e realiza inserção, remoção, consulta e limpeza em tempo constante. |
| Tarefa 2| Árvores binárias | Calcula a soma máxima de um caminho em uma árvore binária representada em pré-ordem. |
| Tarefa 3 | Ordenação e inversões | Calcula o grau de desordem de strings pelo número de inversões e as ordena de forma estável com Counting Sort. |
| Tarefa 4| Programação dinâmica | Encontra o menor valor pagável, maior ou igual ao preço, e a quantidade mínima de moedas necessária. |
| Tarefa 5 | Algoritmo guloso | Determina uma cobertura mínima do intervalo de `0` a `V` usando os intervalos disponíveis. |
